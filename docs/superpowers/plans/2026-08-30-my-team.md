# My Team: Club Selection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user nominate one club as their own, persist it across re-imports, and reach its squad in one click from a `/my-team` route that later squad-planning work can grow into.

**Architecture:** The club name is stored in a new generic `settings` object store (database version 5) behind typed accessors, so it survives `clearAllPlayers()` for the same reason `leagueRankings` does. A `MyTeamProvider` mirrors the existing `CompareContext` pattern and holds the name only — views load rosters through the existing `db.getPlayersByClub()`. The squad table moves out of `TeamProfileView` into a shared `SquadTable` component rendered by both team pages.

**Tech Stack:** React 19 + TypeScript (strict), Vite, Chakra UI 3, React Router 7, `idb`, Playwright.

**Spec:** `docs/superpowers/specs/2026-08-30-my-team-design.md`

```ts
import { getDB, wrapError } from './connection';

const MY_CLUB = 'myClub';

export async function getMyClub(): Promise<string | null> {
  try {
    const db = await getDB();
    const entry = await db.get('settings', MY_CLUB);
    return (entry?.value as string) ?? null;
  } catch {
    return null;
  }
}

export async function setMyClub(club: string | null): Promise<void> {
  try {
    const db = await getDB();
    if (club === null) {
      await db.delete('settings', MY_CLUB);
      return;
    }
    await db.put('settings', { key: MY_CLUB, value: club });
  } catch (error) {
    throw wrapError('save my team', error);
  }
}
```

`getMyClub` swallows its error and returns `null`, matching `getCompareList()` in `src/services/db/compare.ts` — a missing preference must not break a page render. `setMyClub` throws, matching every other writer in the layer.

Note the two `setMyClub`s are different functions with the same name: the context's takes a `string` and only sets state, while `db.setMyClub` takes `string | null` and does the write. The context's persist effect is the single bridge between them.

- [ ] **Step 1: Create the context**

Create `src/contexts/MyTeamContext.tsx`, modelled on `src/contexts/CompareContext.tsx` — load once on mount, persist on change:

```tsx
import { createContext, useContext, useState, useCallback, useEffect, useRef, type ReactNode } from "react";
import { db } from "../services/db";

interface MyTeamContextValue {
  myClub: string | null;
  isLoaded: boolean;
  setMyClub: (club: string) => void;
  clearMyClub: () => void;
}

const MyTeamContext = createContext<MyTeamContextValue | null>(null);

export function MyTeamProvider({ children }: { children: ReactNode }) {
  const [myClub, setMyClubState] = useState<string | null>(null);
  const [isLoaded, setIsLoaded] = useState(false);
  const loaded = useRef(false);

  useEffect(() => {
    db.getMyClub().then((club) => {
      setMyClubState(club);
      loaded.current = true;
      setIsLoaded(true);
    });
  }, []);

  useEffect(() => {
    if (!loaded.current) return;
    db.setMyClub(myClub);
  }, [myClub]);

  const setMyClub = useCallback((club: string) => setMyClubState(club), []);
  const clearMyClub = useCallback(() => setMyClubState(null), []);

  return (
    <MyTeamContext.Provider value={{ myClub, isLoaded, setMyClub, clearMyClub }}>
      {children}
    </MyTeamContext.Provider>
  );
}

// eslint-disable-next-line react-refresh/only-export-components
export function useMyTeam() {
  const ctx = useContext(MyTeamContext);
  if (!ctx) throw new Error("useMyTeam must be used within MyTeamProvider");
  return ctx;
}
```

The persist effect is gated on `isLoaded` itself, not a separate ref: the state update from the initial load and the flip to `isLoaded = true` are batched into one commit, so the persist effect only ever fires once the load has resolved, and it fires with whatever `myClub` holds at that point — a value just read from the database, or one the user set while the read was still in flight. Writing back a value that was just read is harmless (it's the same value going back in), so no guard is needed to prevent it. A separate `userChanged` ref exists for a different reason: it stops the load's result from clobbering a club the user picked before the read resolved — the load only applies its result to state when the user has not touched `myClub` themselves.

- [ ] **Step 3: Create the view**

Create `src/views/MyTeamView.tsx`:

```tsx
import { Container, Heading, VStack, Box, Text, Spinner, HStack, Button } from "@chakra-ui/react";
import { useState, useEffect } from "react";
import { Link } from "react-router-dom";
import { db } from "../services/db";
import type { Player } from "../types/types";
import { SearchableSelect } from "../components/SearchableSelect";
import { SquadTable } from "../components/SquadTable";
import { useDocumentTitle } from "../hooks/useDocumentTitle";
import { useMyTeam } from "../contexts/MyTeamContext";

export function MyTeamView() {
  const { myClub, isLoaded, setMyClub, clearMyClub } = useMyTeam();
  useDocumentTitle(myClub ? `My Team: ${myClub}` : "My Team");

  const [clubs, setClubs] = useState<string[] | null>(null);
  const [squad, setSquad] = useState<{ club: string; players: Player[] } | null>(null);
  const [isPicking, setIsPicking] = useState(false);

  useEffect(() => {
    db.getAllPlayers().then((all) => {
      setClubs([...new Set(all.map((p) => p.Club).filter(Boolean))].sort());
    });
  }, []);

  useEffect(() => {
    if (!myClub) return;
    let cancelled = false;
    db.getPlayersByClub(myClub).then((players) => {
      if (!cancelled) setSquad({ club: myClub, players });
    });
    return () => {
      cancelled = true;
    };
  }, [myClub]);

  const handlePick = (club: string) => {
    if (club) setMyClub(club);
    else clearMyClub();
    setIsPicking(false);
  };

  if (!isLoaded || clubs === null) {
    return (
      <Box minH="100vh" p={8}>
        <Container maxW="container.lg">
          <VStack gap={8}>
            <Spinner size="lg" colorPalette="glaucous" />
            <Text color="fg.muted">Loading...</Text>
          </VStack>
        </Container>
      </Box>
    );
  }

  if (!myClub || isPicking) {
    return (
      <Box minH="100vh" p={8}>
        <Container maxW="container.lg">
          <VStack gap={6} align="stretch">
            <Heading size="2xl" colorPalette="glaucous" color="fg.emphasized">
              {myClub ? "Change your club" : "Which club is yours?"}
            </Heading>

            {clubs.length === 0 ? (
              <VStack align="start" gap={4}>
                <Text color="fg.muted">No players imported yet.</Text>
                <Button size="sm" variant="outline" asChild>
                  <Link to="/import">Go to Import</Link>
                </Button>
              </VStack>
            ) : (
              <HStack gap={4}>
                <SearchableSelect
                  options={clubs}
                  value={myClub ?? ""}
                  onChange={handlePick}
                  placeholder="Search clubs..."
                  allLabel="No club selected"
                  width="320px"
                />
                {isPicking && (
                  <Button size="sm" variant="ghost" onClick={() => setIsPicking(false)}>
                    Cancel
                  </Button>
                )}
              </HStack>
            )}
          </VStack>
        </Container>
      </Box>
    );
  }

  const players = squad?.club === myClub ? squad.players : null;

  return (
    <Box minH="100vh" p={8}>
      <Container maxW="container.lg">
        <VStack gap={6} align="stretch">
          <HStack justify="space-between" align="center" flexWrap="wrap" gap={4}>
            <Heading size="2xl" colorPalette="glaucous" color="fg.emphasized">
              {myClub}
            </Heading>
            <Button size="sm" variant="outline" onClick={() => setIsPicking(true)}>
              Change club
            </Button>
          </HStack>

          {players === null ? (
            <Spinner size="lg" colorPalette="glaucous" alignSelf="center" />
          ) : players.length === 0 ? (
            <Text color="fg.muted">{myClub} is not in the current data.</Text>
          ) : (
            <SquadTable players={players} club={myClub} />
          )}
        </VStack>
      </Container>
    </Box>
  );
}
```

Two details are load-bearing:

`squad` stores the club it was loaded for, and the render derives `players` by comparing that club against `myClub`. Storing a bare array instead would flash the old club's roster under the new club's heading for one render after a change.

`SearchableSelect` always prepends an empty-string option labelled by `allLabel`. Here that row is the only way to unset your club, so it reads "No club selected" and `handlePick` routes it to `clearMyClub()`. Do not fork the component to remove the row.

```markdown
## My Team

The user nominates one club as their own. Route: `/my-team`.

- **Storage**: the club name in the `settings` store under key `myClub`, reached only through `db.getMyClub()` / `db.setMyClub()`. Living outside `players` means `clearAllPlayers()` cannot touch it, so the choice survives a re-import.

- **Set from**: the `/my-team` picker, or "Set as My Team" on a team profile.
- **Squad table**: `SquadTable` (`src/components/SquadTable.tsx`) is shared by `/my-team` and `/teams/:teamName`.
- A club missing from the current import is kept, not cleared; the view says so.
```
